# Analytics Workflow

## Overview

CreatorIQ collects and processes creator performance data to provide meaningful analytics and insights through a centralized dashboard.

## Analytics Workflow

1. User logs into the CreatorIQ platform.

2. The user accesses the creator dashboard.

3. The system retrieves creator analytics data.

4. Analytics data includes:

   - Views
   - Likes
   - Comments
   - Shares
   - Reach
   - Followers
   - Engagement Rate

5. The backend processes the analytics data.

6. The processed data is sent to the React frontend through FastAPI APIs.

7. The dashboard displays:

   - KPI Cards
   - Growth Charts
   - Content Performance Charts
   - Engagement Analytics
